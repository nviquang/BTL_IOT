# Tài liệu lưu trữ

Các tài liệu ở đây **đã lỗi thời**, chỉ giữ để tra lại quá trình làm. Chúng còn nhắc tới những
phần đã loại khỏi hệ thống (MQ135, ADS1115, servo và `/door`, MQTT và `server_app.py`, LSTM,
YOLO, ThingsBoard). Thiết kế hiện hành nằm ở `CLAUDE.md`, `README.md` và các file trong `docs/`.

| Đường dẫn | Nội dung |
| --------- | -------- |
| `plans/` | Kế hoạch triển khai ban đầu (05/11 và 08/11/2026) |
| `de_xuat_cai_thien_ai.md`, `de_xuat_cai_thien_ai_v2.md` | Đề xuất AI bản 1 và 2, đã thay bằng `docs/de_xuat_ai_demo_v3.md` |
| `reports/`, `research_notes/` | Nghiên cứu hướng hoàn thiện (servo, ThingsBoard, mô hình phòng); nhóm đã chọn Render + Neon và còi thay cho servo |
